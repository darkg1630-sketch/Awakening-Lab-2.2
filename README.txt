SYSTEM AWAKENING — LAB 2.2

Laboratório experimental independente. Não substitui nem altera a Beta 1.5.

Conteúdo: identidade visual própria com ícone vetorial de cavaleiro sem rosto; missões diárias com XP aumentado; missões fixas de 10–20 XP; painel de comunicação do Sistema com mensagens contextuais; cronômetro de treino e descanso; calistenia e opções de exercícios com equipamento; critérios de promoção de rank mais exigentes.

PUBLICAÇÃO: envie todos os arquivos deste ZIP para a raiz do repositório de laboratório no GitHub Pages, substituindo os arquivos do LAB 2.0. Não envie para o repositório Sistema da Beta 1.5. Depois, em Settings > Pages, confirme main / root. Se já estiver instalado como PWA, atualize a página ou limpe os dados/cache do site para receber a nova versão.

LIMITAÇÕES: mensagens do Sistema são regras locais pré-programadas, não um agente de IA conectado. Os dados ficam no armazenamento local do navegador e não sincronizam entre dispositivos. Sons são sintetizados no navegador, não arquivos de áudio gravados. Use apenas exercícios e variações adequados à sua capacidade; não faça teste máximo nem insista com dor.
